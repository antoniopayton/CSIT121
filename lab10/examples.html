How is it used?

Web Audio API is most ofteny present when sounds or music is invovled for users to interact with in a web. Doing things like turning up and down the volume or clicking buttons that activate sound responses are all controlled by Web Audio API. According to MDN, developers are able to montior how this entire process takes place using this technology. This is a major upgrade to how sound is handled in this day in age.

Another example of this technology is when you play a game. Often time, developers like to implement sound efects during a game to enhance user experience. This can be found in games that require you to jump, slide, run, or anything that involves motion. When these things happen, Web Audio API is at hand. This helps games feel more realistic.
